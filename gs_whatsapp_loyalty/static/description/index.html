Complete Workflow

Configure → Register Customer → Send/Confirm OTP → Welcome Points → Purchase Event → Redeem OTP → Redemption Success → Expiry Alert → Monitor Event Logs

How the Module Works

Connect Odoo Contacts, Accounting and Loyalty with BusinessChat webhooks to send timely WhatsApp updates. Configure a separate endpoint for each event, choose the welcome-points amount and set how far in advance customers should be notified about expiring points.

OTP verification Welcome points Purchase updates Redemption alerts Expiry reminders Event monitoring

Included WhatsApp Events

Event When it is sent
Registration OTP When a new customer starts registration
Welcome After the customer confirms the registration OTP
Post-purchase When a customer invoice is posted
Redemption OTP When a customer begins a points redemption
Redemption success When loyalty points are successfully deducted
Points expiry Daily, for eligible points within the configured reminder window

Setup at a Glance

  1. Install the module and configure your six BusinessChat webhook URLs in Settings → WhatsApp Loyalty.
  2. Set the welcome points and points-expiry reminder window to match your loyalty program.
  3. Use the test tools to verify your webhook connection, then review delivery status and responses in WhatsApp Event Logs.
Integration requirement: This module sends event data to the BusinessChat webhook URLs you provide. A compatible BusinessChat automation and correctly configured endpoints are required to deliver customer messages.

Six Lifecycle Events
1. otp_registration — mobile verification at signup
2. welcome — welcome notification after OTP confirmation
3. post_purchase — invoice and available points notification
4. otp_redeem — OTP for points redemption
5. redeem_success — redemption success notification
6. points_expiry — daily notification for points expiring within the configured alert window
